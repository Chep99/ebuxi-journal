Zugang zum Daten-Repo

Die App liegt öffentlich auf GitHub Pages, deine Fahrten dagegen in einem privaten Repo. Damit dieses Gerät dort lesen und schreiben darf, braucht es einmalig ein Zugriffstoken.

Token erstellen

  1. Auf GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Bei Repository access: Only select repositories → nur das Daten-Repo auswählen
  3. Bei Permissions → Repository permissions → Contents auf Read and write stellen
  4. Ablaufdatum setzen, Token erzeugen und hier einfügen

Sicherheit

Das Token bleibt nur in diesem Browser auf diesem Gerät und wird ausschliesslich an api.github.com geschickt. Es gilt nur für das eine Repo. Wenn du ein Gerät verlierst, das Token auf GitHub widerrufen und hier ein neues eintragen.
